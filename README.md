# Atualizze NFS-e

Emissor de **Notas Fiscais de Serviço eletrônicas (NFS-e)** no **Padrão Nacional**, da **Atualizze Contabilidade**.

## ⬇️ Download

**[Baixar o instalador (versão mais recente)](https://github.com/ATUALIZZE/atualizze-nfse-downloads/releases/latest/download/Instalar-AtualizzeNFSe.exe)**

Todas as versões e o que mudou em cada uma: [Releases](https://github.com/ATUALIZZE/atualizze-nfse-downloads/releases).

## Requisitos

- Windows 10 ou 11 (64 bits)
- Certificado digital **A1** (.pfx) da empresa — ou procuração eletrônica para o escritório de contabilidade
- Internet para emitir as notas

## Instalação

1. Baixe o arquivo `Instalar-AtualizzeNFSe.exe` pelo link acima.
2. Execute e siga as etapas (não é preciso ser administrador).
3. Na primeira abertura, cadastre a empresa e o certificado em **Configurações**.

O aplicativo avisa sozinho quando há uma versão nova e se atualiza com um clique.
Seus dados (notas, empresas, certificados) ficam no seu computador e são mantidos nas atualizações.

## Conferência do arquivo

Cada versão publica junto o arquivo `Instalar-AtualizzeNFSe.exe.sha256`, com o resumo SHA-256 do instalador.
A atualização automática do aplicativo confere esse resumo antes de instalar.
